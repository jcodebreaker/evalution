One run, start to finish

What happens when you press Run. Your own relay-lite is never touched.
  1. Prove the plan again

    A commit changed how relay-lite stores things, so evalution checks the plan still resets everything before using it.

    ~41 s, once
  2. Start evalution's own copy

    A separate relay-lite, on its own ports and its own storage, that sends its traces to evalution.

    ~18 s, once
For each try · 2 in this run
  1. Start clean

    Put back conversations and the memory index, then check they match the starting state. If they don't, the try isn't judged.

    ~7 s
  2. Play the test as a new person

    Sends the test's messages the way a real person would. "Says hello back" sends 1 message.

    ~4 s
  3. Watch what happened

    The reply, the tools it used and in what order, what reached the model, and what it stored.

  4. Decide the result

    Exact checks first. Then a model reads the reply for what can't be checked exactly.

    ~3 s
  1. Remove the copy

    Its containers and storage go with it. Nothing it made is left behind.

How a result is decided

  • Exact
    What was stored, and what reached the model, checked by code. These never vary.
  • Model
    The reply, read by claude-sonnet-5-5 against the test's lines, with quotes as evidence.
  • Not judged
    When it couldn't tell, or the try didn't start clean. It's never counted as a pass.

A test passes when its tries agree. Disagree with a verdict on the test page and evalution learns which lines it gets wrong.
